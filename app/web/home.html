01 · Compare

A/B like a
mastering room.

Two files play on one clock and switch in 12 ms, so you hear the difference, not a gap. Fold to mono, squeeze it through a phone speaker, or loop the one bar you’re unsure of.

Version keys

0 is the album. 1–9 are its versions.

Tap a number and GODMIX lands on the same spot in the song, at the new speed. A plays the album, B the version.

02 · Analysis

Measured,
not guessed.

Every song is measured (on your device) as it comes in: tempo, key on the Camelot wheel, loudness, range and true peak. The numbers drive the transitions and the loudness matching. And because a measurement can be wrong, every one can be corrected by hand.

03 · Sequence

The album,

Notes that
Claude can read.

06 · Export

Ready to
release.

Export the songs in your running order as tagged files, or render the whole album as one file with your exact gaps and a cue sheet. Missing versions are one click away.

Tagged files

Titles, artwork, ISRCs

WAV, FLAC and MP3 with artist, album, track number, year, copyright, ISRC and the cover built in. The WAV and FLAC are bit-exact.

Full album

One file, start to finish

The running order joined with your gaps, sample-accurate, plus a cue sheet and a tracklist with start times. Works for any version too.

Versions on demand

Make what’s missing

Songs without a slowed, sped-up or other-room version show it anyway. Click to design it from the song and render it.

09 · Setup

Three steps
to the room.

Node.js runs the app. Python measures the albums and makes the masters and versions. Nothing leaves your machine.

One go: clone, set up, measure the demo, open the room (Windows)
git clone https://github.com/kylersimzer/godmix-app.git
cd godmix-app
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app/build_data.py
npm start
What the sidebar shows while it makes the demo’s versions
Step 1

Install

Node 20+, Python 3.12 and ffmpeg.

python -m venv .venv .venv\Scripts\python -m pip install -r requirements.txt # macOS/Linux: python3 -m venv .venv, then .venv/bin/python -m pip …
Step 2

Measure the albums

The demo album, 000 by Kyler Simzer, comes with it. Add your own from the app.

# measures the albums for the app .venv\Scripts\python app/build_data.py
Step 3

Open the room

Or double-click GodMix.cmd on Windows.

npm start # → http://localhost:8333/app
